# JettGPT Feature: E2F1 PC Verwaltung

## DeepSeek API-Schlüssel

Lege im Repository-Stammverzeichnis eine lokale Datei namens `.env` an und trage dort den Schlüssel ein:

`DEEPSEEK_API_KEY=dein-deepseek-api-schluessel`

Die Anwendung sucht `.env` im Anwendungsverzeichnis und in übergeordneten Verzeichnissen. `.env` wird von Git ignoriert; teile die Datei nicht und committe den echten API-Schlüssel nicht.
